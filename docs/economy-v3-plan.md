# 经济系统 v3 计划书（游戏化 × 平衡 × 可上线）

> 状态：**设计已确认，待实施**
> 日期：2026-08-11
> 目标：让校园论坛经济系统"有趣、平衡、留得住用户"——双轨成长（积分+经验）+ 四引擎（等级/任务/成就/感谢）
> 模拟器：`/tmp/econ_sim.py`（参数化，可 `python3 econ_sim.py 180 300 [v2|v2full|v3]` 复现）

---

## 一、背景：现状经济系统为什么失败（模拟证据）

当前系统 180 天模拟结果（300 活跃用户，参数全部取自代码真实值）：

| 指标 | 数值 | 问题 |
|---|---|---|
| 积分总量 | 30,000 → **3,310,050** | 110 倍膨胀 |
| 人均余额 | 100 → **11,033** | 积分贬值到无意义 |
| 抽奖净印钞 | **+227 万**（占膨胀 69%） | 单抽 30 成本、期望 240.5（奖品表 weight=1000，含改名卡 6%×1000、改名卡×2 3.5%×2000 等）——**印钞机** |
| 恶意举报刷分 | +81,000 | `reports.ts` 提交即 +5，不校验有效性 |
| 商城消耗 | 仅 24 万 | 只吸收 7% 膨胀 |
| admin 手续费沉淀 | 14,400 | 转账费 50% 归第一个 admin → 排行榜霸榜 |

**根因**：收入无边界（抽奖正期望/举报刷分）+ 消费出口枯竭（永久道具买一次即止）+ 无通缩（税务已删）。

---

## 二、v3 设计总览

```
行为（发帖/评论/签到/被赞/被感谢）
  ├─→ 积分（货币）：商城/抽奖/付费帖/转账 —— 平衡底座（v2-full 数值）
  ├─→ 经验（成长）：升级解锁 —— 目标感
  ├─→ 任务（日常）：每天有事做 —— 习惯养成
  └─→ 成就（收集）：徽章炫耀 —— 身份认同
```

## 三、引擎详设

### 引擎一：经验等级（成长感）
- **经验来源**（不给积分，避免印钞）：发帖+5、评论+2、被赞+1、签到+10、被感谢+5
- **等级表**（30 级）：

| 等级段 | 名称 | 经验/级 | 升级解锁 |
|---|---|---|---|
| 1-4 | 大一新生 → 大二学长 | 100 | — |
| 5-9 | 大三学霸 | 300 | 自定义称号使用权 |
| 10-14 | 大四达人 | 500 | 头像框使用权 |
| 15-24 | 校园风云人物 | 800 | 彩色评论框 |
| 25-30 | 校园传奇 | 1200 | 鎏金标题 |

- **升级礼包**：每次升级 +50 积分（人均累计 ~1500，一次性可控）
- **展示**：资料页 + 帖子作者旁显示等级徽章（名称/进度条）
- **表结构**：`users` 加 `exp INTEGER DEFAULT 0`（等级由 exp 计算，不存列）；或 `user_levels` 表
- **接口**：`GET /api/users/:id/profile` 返回 exp/level/level_name（getPublicUser 扩展）；升级检测在加经验处统一处理

### 引擎二：每日任务（目标感）
- **任务项**（每日 0 点 UTC+8 重置）：

| 任务 | 奖励 |
|---|---|
| 签到 | 积分（现有签到） |
| 发布 1 个帖子 | +8 积分 +15 经验 |
| 发表 2 条评论 | +4 积分 +10 经验 |
| 获得 1 次点赞 | +4 积分 +10 经验 |
| **完成全部 3 项** | 额外宝箱 +14 积分 |

- 日总注入 ≈ 30/人（50% 用户完成），模拟验证可控
- **表结构**：`daily_tasks (user_id, date, task_type, done, claimed)`，UNIQUE(user_id, date, task_type)；完成检测钩子在 posts/comments/likes handler 里
- **接口**：`GET /api/tasks/today`（状态+进度）、`POST /api/tasks/claim`（领取已完成任务奖励）
- **前端**：任务面板（首页或单独页 /tasks），进度条+一键领取

### 引擎三：成就徽章（收集向，一次性）
| 成就 | 条件 | 奖励 |
|---|---|---|
| 初来乍到 | 首次发帖 | +50 积分 + 徽章 |
| 人气王 | 被赞累计 100 次 | +200 |
| 笔耕不辍 | 发帖累计 100 篇 | +300 |
| 全勤王 | 连续签到 30 天 | +300 |
| 热心肠 | 被感谢累计 50 次 | +200 |
| 欧皇 | 抽中 SSR | +100 |

- 人均一次性上限 ~800，前 30 天逐步解锁，不构成通胀源
- **表结构**：`achievements (user_id, key, unlocked_at)`，UNIQUE(user_id, key)
- **接口**：`GET /api/achievements`（我的/他人资料页展示）
- **前端**：资料页徽章墙（已解锁彩色/未解锁灰色+条件提示）

### 引擎四：社交「感谢」
- 帖/评论旁「感谢」按钮：**免费**，每人每日限 5 次（防刷）
- 被感谢者：+1 经验 + 感谢计数（成就「热心肠」）
- **表结构**：`thanks (user_id, target_type, target_id, created_at)`，UNIQUE(user_id, target_type, target_id) + 每日次数检查（coin_transactions 同款 UTC+8 日窗）
- **接口**：`POST /api/thanks`（toggle 或仅单向，建议仅单向：感谢不可撤销）
- **前端**：PostDetail 帖/评论操作区「感谢」按钮 + 计数

## 五、新奖池（负期望：40 成本 → EV≈32）

权重总量 1000，稀有度 N500/R300/SR150/SSR50：

| 稀有度 | 奖品（权重） | 价值 |
|---|---|---|
| N | 3积分(200) 7积分(150) 10积分(100) 今日运势(50) | 硬币 EV≈2.65 |
| R | 20积分(100) 提升卡(50) 高亮卡(80→权重50) 35积分(40) VIP体验卡1天(30) 头像框7天(30) | 硬币 EV≈3.4 |
| SR | 70积分(40) 称号7天(35) 炫彩3天(35) 100积分(40) | 硬币 EV≈6.8 |
| SSR | 350积分(15) S-VIP3天(10) 炫彩标题7天(10) 全服公告(7) 称号30天(8) | 硬币 EV≈5.25 |

- 硬币 EV≈18.1 + 道具折价 EV≈14 → **总 EV≈32（成本 40，净亏 20%）**
- **移除**：改名卡、改名卡×2（保商城）
- 保底机制保留（软 50 / 硬 80，后台可配）

## 六、消费端道具体系（三类卡片）

| 类型 | 道具 | 价格 | 机制 |
|---|---|---|---|
| 永久型 | 改名卡 / 简约边框 / 鎏金标题 | 1000 / 500 / 1500 | 抽奖不产出，商城唯一 |
| 限时装饰 | 自定义称号(10天) / 炫彩昵称(30天) / 彩色评论框(30天) / **头像框(30天)新增商城直购** | 800 / 2000 / 1500 / 1200 | 到期续费 → 持续消费 |
| 消耗型 | 提升卡 / 高亮卡 / 置顶卡 / 大喇叭 | 50 / 80 / 500 / 抽奖限定 | 发帖配套，大喇叭每日限 1 次 |

|---|---|---|---|---|
| 人均余额 | 11,033 | 2,635 | 1,177 | **4,184** |
| 抽奖净注入 | +227 万 | -19 万 | -8.6 万 | **-8.6 万** |
| 商城消费 | 24 万 | 22 万 | 77 万 | **102 万** |
| 刷分 | 有 | 无 | 无 | **无** |

## 九、风险与注意
- 经验/任务/成就的**钩子必须幂等**（防重复计数）：用 UNIQUE 约束 + INSERT OR IGNORE
- 任务重置用 UTC+8 日窗（复用 coins.ts canEarnToday 的日期计算模式）
- 等级纯计算不存列 → 升级礼包需记录"已发等级"（`users.last_rewarded_level`）避免重复发放
- 成就奖励全部一次性：`achievements` 表存在即不发
- 感谢按钮免费 → 必须日限 5 次 + UNIQUE 防重复感谢同一内容
- 模拟器参数与代码实现若有偏差，以代码为准并回填模拟器
