# UI 布局优化方案（重点：布局与信息架构，非视觉细节）

> 日期：2026-08-12 ｜ 状态：方案待确认
> 原则：只动空间结构，不动视觉元素（避免"廉价感"）；小步、可逆、每批验证

---

## 一、布局问题清单（审计确认）

1. **内容宽度 6 档跳变**（最严重）：Layout main 是 max-w-6xl，但各页自行包裹——PostDetail 5xl / CreatePost·Profile 4xl / Coins 3xl / CheckIn·Tasks·Warehouse·Shop·Leaderboard 2xl / Lottery lg。**页面切换时内容宽度肉眼跳变**，是"布局稀烂"的第一观感来源。
2. **Profile 是"纵向堆叠大杂烩"**：头部卡 + 手风琴（资料编辑/安全设置）+ 成长面板（等级+成就墙）+ VIP 入口 + 邀请卡 + 帖子/收藏 tab 全部纵向堆在一个长页面，信息要找半天，深链不可达。
3. **PostDetail 操作区挤在内容底部一条**：点赞/收藏/举报/打赏/感谢 + 付费墙 + 红包卡全堆在正文下方，评论区被挤到后面；作者行信息（等级/称号）和操作分散两处。
4. **Home 顶部控件堆叠**：搜索框 + 发布按钮 + 分类 chips + 排序 + 关注开关全挤在首屏，信息流起点被推低。
5. **Coins 页纵向堆叠**：余额卡 + 功能入口网格 + 今日收入 + 转账表单 + 交易记录，五个区块一列排开，主次不分（交易记录才是高频浏览内容）。
6. **工具页宽度不一**：Shop/Warehouse/CheckIn/Tasks/Lottery/Leaderboard 各自定宽，同类型页面观感割裂。
7. **返回按钮三套样式**、无面包屑；桌面导航与移动底导入口分布不一致。
8. **Admin/Moderator 侧边栏已有**（此前改造过），但内容区面板宽度/间距未统一。

---

## 二、布局统一规范（全站骨架）

### 1. 内容宽度三档（消灭 6 档跳变）
| 档位 | 宽度 | 适用页面 |
|---|---|---|
| A 阅读 | max-w-4xl（896px） | Home、PostDetail、Boards、Leaderboard |
| B 工具 | max-w-3xl（768px） | Coins、Shop、Warehouse、CheckIn、Tasks、Lottery、VIP、ActiveEffects |
| C 表单 | max-w-md（448px） | Login、Register、ForgotPassword |
| D 后台 | 侧边栏 + 内容自适应 | Admin、Moderator |

- Layout 的 main 改为不设宽度（或 max-w-none），**宽度由页面级容器决定**，同一档页面严格同宽
- 页内不再出现第二层 max-w 包裹

### 2. 统一页面骨架模板
```
┌──────────────────────────────────────────┐
│ 页头：返回（可选）│ 标题 │ 副标题 │ 主操作按钮（右） │
├──────────────────────────────────────────┤
│ 内容区（按档位定宽）                        │
└──────────────────────────────────────────┘
```
- 所有页面套同一页头模式（返回按钮位置/样式统一为一种）
- 区块间距统一（区块间 mb-6，页内卡间距 gap-4）

### 3. 统一卡片与表格容器
- 页面内所有"卡"统一为同一容器（边框/圆角/内边距同一套类，抽一个 `Card` 组件或统一类名）
- 列表/表格统一表头样式（后台已抽 thCls/tdCls，推广到普通页）

## 三、核心页面布局改造设计

### 1. Profile —— 左右两栏（最大收益）
```
桌面（md+）：
┌──────────┬──────────────────────────────┐
│ 左栏(固定) │ 右栏 Tab：                    │
│ 头像/昵称  │ 帖子 │ 收藏 │ 成长 │ 设置     │
│ 等级+进度  │                              │
│ 角色徽章   │  (Tab 内容)                  │
│ 关注按钮   │                              │
│ 成就概览   │                              │
└──────────┴──────────────────────────────┘
移动端：左栏信息并入头部卡，Tab 保持
```
- 手风琴（资料编辑/安全设置）拆进"设置"Tab 内
- 邀请卡、VIP 入口并入设置 Tab 或头部
- 深链：`/profile?tab=settings` 可达

### 2. Home —— 顶部重组 + 单栏信息流
```
┌────────────────────────────────────┐
│ [搜索框........................] [＋发布] │
│ [全部][校园][二手]...（横向滚动chips） [排序▾] │
├────────────────────────────────────┤
│ 信息流（卡片列表）                    │
│ 分页                                │
└────────────────────────────────────┘
```
- 搜索/发布合并一行；分类 chips 与排序合并一行（关注开关并入排序下拉或 chips 首位）
- 信息流保持单栏（校园论坛不需要右侧栏）

### 3. PostDetail —— 操作区上移 + 评论区独立
```
┌────────────────────────────────────┐
│ 返回 │ 标题                          │
│ 作者行：头像 昵称 等级 时间     [点赞][收藏] │
├────────────────────────────────────┤
│ 正文（含付费墙/红包卡/装饰）            │
├────────────────────────────────────┤
│ 操作条：举报 打赏 感谢 分享             │
├────────────────────────────────────┤
│ 评论：输入框 → 列表（无限滚动）          │
└────────────────────────────────────┘
```
- 点赞/收藏上移到作者行右侧（高频操作）；举报/打赏/感谢留操作条
- 评论筛选改为**服务端参数**（解决客户端筛选与分页冲突），或去掉"仅看楼主"外的筛选

### 4. Coins —— 两栏：左概览右明细
```
┌──────────────┬─────────────────────┐
│ 余额卡+今日收入 │ 交易记录（主内容，分页）  │
│ 功能入口网格    │                     │
│ 转账（折叠）    │                     │
└──────────────┴─────────────────────┘
```
- 交易记录是高频浏览 → 给最大空间；转账折叠为可展开
- 移动端回单栏（余额→转账→记录）

### 5. Shop / Warehouse —— 宽度统一 + 网格一致
- 商品卡与道具卡统一为同一网格（grid-cols-1 sm:grid-cols-2 已有，统一容器样式）
- Shop 顶部余额条与 Warehouse 顶部对齐

### 6. Admin / Moderator —— 内容区统一
- 面板容器统一宽度/间距（现有侧边栏不动）
- 列表/卡片/表格三种面板形态保持（Pinned/Reports/Unban 是列表流），统一表头与操作列位置

## 四、导航统一

1. 返回按钮全站统一为一种（组件化 BackButton）
2. 桌面导航与移动底导入口对齐（VIP/任务等两边都有）
3. 顶部 Logo 区点击回首页（已有）

## 五、实施批次（每批独立可验证）

| 批次 | 内容 | 影响面 | 风险 |
|---|---|---|---|
| 1 | 宽度三档统一 + 页面骨架模板 + 返回按钮统一 | 全站 18 页机械替换 | 低（纯结构） |
| 2 | Profile 两栏重构 | Profile.tsx 大改 | 中（功能多，需逐 Tab 验证） |
| 3 | PostDetail 布局（操作区上移 + 评论筛选服务端化） | PostDetail.tsx + comments 接口 | 中 |
| 4 | Coins 两栏 + Shop/Warehouse 统一 | 3 个页面 | 低-中 |
| 5 | Home 顶部重组 + 导航统一 | Home.tsx + Layout.tsx | 低 |

## 六、验证方式
- 每批：tsc 0 错误 + build + 浏览器人工过一遍（重点：宽度跳变消失、Profile Tab 可用、PostDetail 操作可达）
- 交互回归：现有 25 项 API 冒烟不受影响（后端不动）

## 七、风险与注意
- 只动空间结构，**视觉元素（颜色/圆角/图标）一律不动**——避免"廉价感"翻车
- Profile 重构期间保持现有所有功能入口不丢（邀请/VIP/解封/成就等逐个核对）
- 移动端优先验证（底部导航遮挡、弹窗范式）
