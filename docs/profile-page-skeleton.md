# 个人主页（Profile）页面骨架与功能清单

> 用途：交给设计方做 UI 重排的输入文档。描述**当前实现**的结构、数据与交互契约；设计时结构可重排，但标注为「契约」的部分（路由、数据字段、权限、API 行为）不要改。
> 源码：`frontend/src/pages/Profile.tsx`（约 1040 行）、路由 `/profile`（自己）与 `/user/:id`（他人）

---

## 一、页面定位与权限

| 项目 | 说明 |
|---|---|
| 路由 | `/profile` = 自己的主页；`/user/:id` = 他人主页 |
| 未登录访问 `/profile` | 跳转登录页并带 `from=/profile` 回跳 |
| 他人主页能看什么 | **仅「帖子」tab**（收藏/成长/邀请/设置都只有自己可见） |
| 自己的主页 | 5 个 tab：帖子 / ⭐ 收藏 / 📈 成长 / 🤝 邀请 / ⚙️ 设置 |
| 页面标题 | `{用户名} - CloudForum` |
| 容器宽度 | `max-w-3xl`（768px）居中，纵向卡片间距 20px（`space-y-5`） |

┌─ 卡片 1：用户头部  (bg-white rounded-2xl border overflow-hidden)

│   └─ 资料区（px-6 pb-6）

│       │    └─ 「+」按钮（仅自己；跳裁剪弹窗）
│       ├─ 用户名 + 徽章行（可换行）：

│       ├─ 个人简介（bio）
│       └─ 元信息行：注册于 {日期} · {N} 篇帖子

├─ Tab 导航条（bg-white rounded-xl border p-1.5；横向排列、可换行；选中态＝主色实底）

├─ 卡片 2：👑 VIP 入口（自己可见，**当前实现不随 tab 切换，任何 tab 都在**）

│    未开通：「👑 升级 VIP / 解锁更多特权 / 💎」        点击 → /vip

## 三、各 Tab 功能骨架

### 3.1 帖子 tab（自己 + 他人可见）

- 标题：`帖子 ({总数})`
- 列表项（每条可点进 `/post/:id`）：**标题**（单行截断）+ 元信息行（分类标签 / 相对时间 / 今日运势标签 / 浏览 N / 评论 N / 赞 N）
- 状态：加载中（骨架屏 3 条）/ 空态（自己：「你还没有发过帖子」；他人：「该用户还没有发过帖子」）
- 分页：每页 10 条，底部「← 上一页  n/N  下一页 →」（超过 1 页才显示）
- 数据：`GET /posts?userId=&page=&pageSize=10`（`total` 用于标题与分页）

### 3.2 收藏 tab（仅自己）

- 标题：`⭐ 收藏 ({总数})`
- 列表项（点进 `/post/:id`）：标题 + 「作者名 · 💬 评论数 · ❤️ 点赞数」
- 状态：加载中（骨架屏）/ 空态「暂无收藏 / 去首页看看有没有感兴趣的帖子」
- 分页：每页 20 条（后端默认），底部同款分页器
- 数据：`GET /bookmarks?page=`（进入 tab 且列表为空时懒加载）

### 3.3 成长 tab（仅自己）

**区块 A：等级进度**
- 标题「📈 成长」+ 右上 `Lv.N {称号}`（如 Lv.1 初学乍练）
- 进度条（主色填充，按当前等级内经验百分比）
- 说明行：`经验 {当前}/{本级所需}，升级还需 {剩余} 经验`；满级显示「已满级 🎉」

**区块 B：🏆 成就（可折叠区块，标题行点击折叠/展开）**
- 标题行右侧：`已解锁 N/M` + 「查看成就殿堂 →」（跳 `/achievements`）
- 成就网格（2 列 / 桌面 3 列），每格：图标（🏅 已解锁 / 🔒 未解锁灰显）+ 成就名 + 描述（2 行截断）
- **未解锁**格底部显示奖励标签：`🪙 +200 积分`、`👑 称号「人气王」·7天`、`⚡ +50 经验`、`🖼️ 头像框·30天` 等
- 排序：已解锁优先
- 状态：折叠提示语 / 加载中 / 失败（含「重试」按钮）
- 数据：`GET /achievements`（挂载时 + 切到本 tab 时刷新）

### 3.4 邀请 tab（仅自己）

单张绿色系卡片：
- 标题「🤝 邀请好友」+ 说明「每邀请一位好友注册成功，你获得 **+120 积分**（同时只能有 1 个邀请码，使用后可再生成）」
- 右侧按钮：无可用码时「+ 生成邀请码」；有码时显示灰字「邀请码使用后可再生成」
- 邀请码列表（每行）：等宽字体邀请码 + 「复制」+ 「复制邀请链接」（`{origin}/invite/{code}`）
- 空态：「还没有邀请码，点击右上角生成一个分享给好友吧」
- 底部统计：`已邀请 N 人 · 累计获得 M 积分`
- 数据：`GET /auth/invites`、`POST /auth/invites`（生成后本地立即插入，再后台静默校准）

### 3.5 设置 tab（仅自己，**当前拆成两张卡片**）

**卡片 A：编辑资料**
1. 邮箱未验证提示条（仅 `email_verified=0` 时）：黄条 + 「发送验证码」+「我已收到验证码」（展开输入 6 位码 + 「验证」）
2. 用户名：输入框 + 「保存」
3. 个人简介：多行输入（上限 500 字）+ 「保存简介」
4. 自定义头衔（仅 VIP 可见）：输入框（≤30 字）+ 「保存」
5. 昵称主题（仅 S VIP+ 可见）：4 个渐变色主题按钮（红金/紫粉/蓝紫/绿金）+ 「保存主题」+ 「有未保存的更改」提示 + 预览区
6. 邮箱：显示当前邮箱 + 「更换邮箱」按钮（跳 `/change-email`）

**卡片 B：安全设置**（桌面两列：左＝修改密码；右＝管理/退出/注销）
- 左列「修改密码」：说明文字 + 「修改密码」按钮（跳 `/change-password`）
- 右列：
  - 「管理」区（仅管理员/巡查员）：「进入管理后台」按钮（跳 `/admin`）
  - 「退出登录」区：「退出当前账号」按钮（弹确认框）
  - 「注销账户」区：说明「3 天冷静期」+「注销账户」按钮（弹三级流程）；
    **若已提交注销**：改成黄色卡「⏳ 账户注销待处理 / 将在 {X天Y小时} 后自动注销」+「取消注销」按钮

## 四、弹窗 / 浮层清单

| 组件 | 触发 | 内容与行为 |
|---|---|---|
| 裁剪弹窗 CropModal | 换头像 / 换背景 | 选图后裁剪：头像 1:1（导出 ≤1024px）、背景 5:2（导出 ≤2048px）；确认后压缩上传 → 更新资料 |
| 图片预览 Lightbox | 点头像 / 点背景图 | 全屏查看，支持缩放（拖动缩放、滚轮缩放，最大 3 倍） |
| 解封申请确认 ConfirmModal | 「提交解封申请」 | 提示扣 500 积分作保证金（通过不退、失败全退）|
| 退出登录确认 ConfirmModal | 「退出当前账号」 | 二次确认后清会话并回首页 |
| 注销账户弹窗（三步，Portal） | 「注销账户」 | ①警告+3 天冷静期 → ②输入密码验证 → ③5 秒冷静倒计时后才可「确认提交」；提交成功后提示并登出 |

## 五、状态与边界（设计需覆盖）

1. **加载态**：资料未就绪整页骨架屏；帖子/收藏列表骨架屏；成就区「加载中」；上传中遮罩（背景）与「上传中...」（头像）。
2. **错误态**：用户不存在/加载失败 → 独立错误卡（😕 + 「返回首页」）；成就加载失败 → 卡片内「重试」。
3. **空态**：无帖子（区分自己/他人文案）、无收藏、无邀请码、无成就（成就区总有内容，不会空）。
4. **权限差异**：他人主页只有「帖子」tab；未登录访客无关注按钮；管理员/巡查员多「进入管理后台」；VIP 多「自定义头衔」；S VIP+ 多「昵称主题」。
5. **特殊态**：被封禁（徽章 + 可展开详情 + 自己可申请解封）、注销待处理（黄色提示卡 + 取消注销）、邮箱未验证（黄色提示条）。
6. **消息反馈**：页面顶部绿/红条（3 秒自动消失）。
7. **响应式**：头部在窄屏纵向居中（头像上、信息下），`sm` 以上改横向；Tab 条可换行；设置页 `md` 以上两列，窄屏单列。

## 六、可重排 / 需注意的现状

**可自由重排（纯呈现）**：卡片顺序、Tab 是否改侧边栏/分段控件、头部背景与头像的布局、成就网格列数、设置页分区方式、空态插画、按钮主次与配色层级。

**当前实现里值得改进、设计时可一并考虑的**：

1. **VIP 入口卡不随 tab 切换**（任何 tab 都显示在 Tab 条下方）——位置容易被误认为「本 tab 的内容」。
2. **设置页拆成两张卡片**（编辑资料 + 安全设置），信息密度高、纵向很长；「修改密码/更换邮箱」已改为跳独立页面，设置页可以更轻。
3. **成长 tab 与成就殿堂内容重叠**（成长页内嵌成就墙 + 「查看成就殿堂」外链），可考虑合并职责。
4. **帖子 tab 的列表项信息较散**（分类/时间/运势/浏览/评论/赞 一行挤 6 项）。
5. **收藏列表与帖子列表样式不同**（收藏是作者+评论/点赞，帖子是分类+浏览/评论/赞）。
6. **邀请卡片是独立配色（绿）**，与整页白卡风格不统一。

**契约（不要改）**：路由与 tab 的权限划分（他人主页仅帖子）、各 tab 的分页大小（帖子 10 / 收藏 20）、成就区仅自己可见、注销三步流程（含 5 秒冷静）、邀请码「同时仅 1 个未使用」、解封申请扣 500 积分、上传走裁剪+压缩链路、以下 API 与字段含义不变：

```
GET  /users/:id/profile       用户资料（含 exp/vip_tier/title_badge/banned_until/…）
GET  /posts?userId=&page=     该用户帖子（total 用于分页）
GET  /bookmarks?page=         我的收藏
GET  /achievements            我的成就（含 rewards、unlocked）
GET  /auth/invites            我的邀请码与实际邀请统计
POST /auth/invites            生成邀请码
POST /follows/:id/toggle      关注/取关
PUT  /users/profile|avatar|banner|title|nick-theme   资料更新
POST /auth/username           改用户名
POST /auth/email/resend|verify-register              邮箱验证徽章
POST /auth/verify-password    注销前密码验证
POST /auth/account            提交注销
POST /auth/cancel-deletion    取消注销
POST /unban/request           解封申请
POST /upload/image            图片上传（裁剪后）
```

## 七、给设计方的输出期望（建议）

1. 桌面 + 移动两套布局示意（页面宽度以 `max-w-3xl` 为基准，移动端 375px 起）。
2. 明确各区块的层级（标题/正文/辅助文字/标签）与间距节奏。
3. Tab 的呈现形式（当前是胶囊按钮条，可改为分段控件/侧边导航）。
4. 设置页的分组方案（把「资料 / 账号安全 / 危险操作」拆清楚）。
5. 空态、加载态、错误态、上传中的视觉稿。
6. 特殊态（封禁 / 注销待处理 / 邮箱未验证 / VIP 等级差异）的表现。
