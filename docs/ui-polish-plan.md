# 首页布局与视觉质感升级计划书

> 状态：**待确认** ｜ 日期：2026-08-13
> 目标：① 利用桌面端左右留白（双栏布局）；② 消除"廉价感"（视觉体系收敛）
> 原则：小步、可回退（当前 checkpoint `2a4c74d` 已保存）

## 一、现状诊断

### 1.1 布局问题：留白浪费

| 项 | 现状 | 影响 |
|---|---|---|
| Home 容器 | `max-w-4xl`（896px）单栏 | 1440px 屏左右各留 ~270px；1920px 屏留 ~500px |
| 顶栏（Layout） | `max-w-6xl`（1152px） | 顶栏比内容宽，视觉上"内容缩在中间" |
| 信息密度 | 卡片式列表，每帖 ~150px | 一屏仅 5-6 帖，右侧完全空闲 |

### 1.2 视觉"廉价感"来源（已定位到具体位置）

| 症状 | 位置 | 大厂做法对照 |
|---|---|---|
| **彩色徽章泛滥**：同排出现黄(置顶)/橙(提升)/琥珀(高亮/付费) 3-4 色 | Home.tsx 标记行、Profile 徽章 | V2EX/知乎：非关键信息一律**灰色小字**，彩色只留给"进行中状态" |
| **渐变滥用**：金色/琥珀渐变卡（VIP 入口、邀请卡、宝箱卡、抽奖状态卡、打赏按钮、高亮帖） | Profile/Shop/Tasks/LotteryCoins/PostDetail/Home | Reddit：**白卡为主**，渐变只用于品牌 CTA 按钮 |
| **图标三套混用**：FontAwesome + emoji（📌🚀✨🧧）+ 手写 SVG（搜索）+ 文本符号（→✕） | 全站 | 大厂：同一图标体系（一套线性图标），emoji 仅限情感化场景 |
| **字号碎片化**：text-[10px]/[11px]/[13px]/[15px] 与 text-xs/sm 并存 | 全站 | 统一字号阶梯：14/13/12/11 |
| **动效过度**：hover:shadow-lg + hover:-translate-y-0.5 + transition-all 叠加 | Home 卡片 | 大厂：hover 只做**极淡底色**或阴影加深一档，不位移 |
| **页面全白无层次**：body 纯白，卡片靠边框区分 | index.css body @apply bg-white | V2EX/知乎：**页面浅灰底 + 白色卡片**，层次来自背景对比 |

## 二、大厂论坛设计模式学习（V2EX / Reddit / 知乎 / NGA）

共性 5 条（可直接借鉴）：

1. **双栏消化留白**：主内容流 + 右侧边栏（公告/热门/入口/统计/排行），桌面端几乎全员如此；移动端降级单栏
2. **层次靠背景，不靠边框阴影**：页面浅灰 `#f5f6f7` + 白色内容卡，卡片之间 0 边框 0 阴影也能清晰分层
3. **颜色极度节制**：1 个品牌色 + 灰阶；彩色 = 状态/稀有信息专用，且**同排最多 1-2 个彩色**
4. **徽章降噪**：能用小字说明的绝不用彩色块（V2EX 的"回复数"就是右侧灰色数字）
5. **动效克制**：hover 仅底色微变；卡片不做位移/缩放/重阴影

## 三、方案设计

### 3.1 首页双栏布局（解决留白）

```
┌────────────────────────────────────────────────────────┐
│ 顶栏（max-w-6xl，不变）                                  │
├────────────────────────────────────────────────────────┤
│  搜索栏（跨两栏，保持不变）                               │
│  ┌──────────────────────────┬──────────────────────┐   │
│  │ 工具栏：排序 + 发布        │ ① 公告卡              │   │
│  │ 分类 chips（横向滚动）     │ ② 我的状态卡          │   │
│  │                          │    （登录/积分/VIP入口）│   │
│  │ 帖子卡片列表（space-y-2.5）│ ③ 板块导航卡           │   │
│  │  （信息密度保持不变）       │ ④ 热门帖子（hot top5） │   │
│  │                          │ ⑤ 金币排行入口         │   │
│  │ 分页                      │                      │   │
│  └──────────────────────────┴──────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

- **容器**：Home 从 `max-w-4xl` → `max-w-6xl`（与顶栏对齐，= 1152px），内部 `grid lg:grid-cols-[1fr_300px] gap-6`
- **右侧栏**（仅 `lg+` 显示，移动端自动隐藏）：
  | 卡 | 内容 | 数据来源 |
  |---|---|---|
  | ① 公告 | 全站公告文案 | `GET /settings/public`（已有 announcement 接口，Home 已调用？未用则补） |
  | ② 我的状态 | 未登录：登录/注册按钮；已登录：积分余额 + VIP 徽章 + 我的红包/仓库快捷入口 | auth + coins.balance |
  | ③ 板块导航 | 8 个板块卡片（名称+简介），点击直达筛选 | categories 已加载 |
  | ④ 热门帖子 | 按 hot 排序 top 5 标题列表 | 复用 postsApi.list({sort:'hot', pageSize:5}) |
  | ⑤ 排行入口 | 金币榜入口卡片 | 静态 Link → /leaderboard |
- **顶部工具栏精简**：分类 chips 保持（移动端友好），宽度让位给右侧栏后仍放得下

### 3.2 视觉体系升级（去廉价感）

**A. 全局 token（index.css）**
```css
/* 页面底色：浅灰底 + 白卡（层次来自背景对比） */
body { @apply bg-[#f6f7f9] text-gray-900; }
.dark body { background-color: #000; }  /* 暗色保持纯黑体系 */

/* 边框统一：更细更淡 */
--border-color: #e8e8e8;   /* 浅色模式（.dark 已有 #222） */
```

**B. 徽章/标签规范（全站统一）**
| 类型 | 规范 | 例子 |
|---|---|---|
| 常规标签（板块/称号/等级） | **灰色小字**（bg-gray-100 text-gray-500） | 分类、Lv、称号 |
| 状态标签（置顶/提升/高亮/付费） | 保留彩色但**同排限 2 色**：置顶黄 + 其余并入灰 | 置顶 📌 黄；提升/高亮/炫彩/付费→灰底或只留一个主色 |
| 权限徽章（管理员/巡查员/VIP） | 保留（身份标识属必要彩色） | 红色/黄色/VIP 渐变 |

**C. 图标统一**
- 操作类一律 FontAwesome（faThumbtack 等）；**删除手写 SVG**（搜索/空态图标改 FA）
- emoji 仅限：道具/红包/情感化（🧧🖼️📦）保留，标记类 emoji（📌🚀✨🌈🔒）改 FA 或纯文字

**D. 渐变红线**
- 页面功能卡（VIP 入口/邀请卡/宝箱卡/余额条）**渐变改纯白卡 + 左侧小图标**
- 仅保留：道具效果（高亮帖/背景卡）、品牌 CTA 按钮（primary 渐变）——这两类有"溢价感"，本就该突出

**E. 动效/圆角收敛**
- hover 一律 `hover:bg-gray-50` 或 shadow 加深一档，**删除 -translate-y-0.5**
- 圆角三档：卡片 rounded-xl（列表/功能卡）、弹窗 rounded-2xl、按钮 rounded-lg

### 3.3 范围（本次只动首页 + 全局 token）

| 文件 | 改动 |
|---|---|
| Home.tsx | 双栏布局 + 右侧栏组件；标记行彩色收敛；hover 去位移；分类 chips 样式统一 |
| index.css | 页面底色浅灰；border 统一；新增 token 注释 |
| Layout.tsx | 顶栏/页面底色适配（body 变色后检查 header 白色卡协调） |
| 右侧栏组件 | 新建 `HomeSidebar.tsx`（公告/我的/板块/热门/排行） |

其余页面（Profile/Shop/Tasks 等的渐变卡收敛）列为**批次 2**，本计划书先确认首页方案。

## 五、验收标准

1. 1920px 屏：首页左右无大块留白，右侧栏有信息承载
2. 一屏信息密度与现在持平或更高（右侧栏不挤压主列表）
3. 首页同排彩色徽章 ≤ 2 色；无手写 SVG 图标
4. 暗色模式全部同步（右侧栏卡片适配）
5. tsc 0 错误 + vite build 通过；checkpoint 可回退
